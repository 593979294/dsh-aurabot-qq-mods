# 自主上网（rss-reader）

让她自己上网看点东西：定时读你给的 RSS / Atom 订阅源，挑几条可能有意思的，
交给**主动发言决策层**决定要不要、什么时候、用什么口吻跟主人聊。

## 它做什么

- 按你设的间隔（默认 2 小时，带 ±20% 抖动）拉取订阅源，支持 RSS 2.0 / Atom / RDF；
- 已读去重（同一件事不会反复喂），单源连续失败自动退避（2 分钟起翻倍，封顶 6 小时）；
- 用「关键词 + 新鲜度」粗筛一遍，只挑达到兴趣门槛的条目，再按每日额度限量；
- 挑出来的条目**不直接发送**，而是交给主动发言决策层（出站策略的 `api.proactive.submit`），
  由目的引擎决定发不发——它不想说就不说；没装出站策略时退化为「只进素材池」，等引擎来取。

## 怎么用

1. 面板里打开本模块，填订阅源（每行一个 RSS/Atom 地址，`#` 开头是注释）；
2. 设定「多久看一次」「每天最多挑几条」「兴趣门槛」；
3. 「交给谁」建议保持默认的「主动发言决策」——这样她看完了要不要跟你说是她自己定，不会刷屏。

如果你想让她只是"知道"这些内容、不主动开口，把「每天最多挑几条」设成 0 即可。

## 会访问哪些网址

只访问**你自己填写的订阅源地址**，不会访问任何内置或第三方站点，不上传任何内容。
订阅内容是外部不可信数据：本模块只取标题与摘要的纯文本，去标签去实体、截断长度，
不当指令执行；交出去时明确标注为「外部内容」。

## 数据存放

状态写在插件数据目录的 `rss-state.json`（已读账本、失败退避、当日计数），
模块源码目录不写任何数据。卸载模块后该文件仍留在数据目录，可手动删除。

## 权限

`network`（拉订阅源）、`filesystem`（读写自己的状态文件）、`plugin-config`（读本模块设置）。
