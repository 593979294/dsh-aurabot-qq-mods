# 刷小红书（xhs）

用专用浏览器（Edge/Chrome，独立资料目录）刷小红书网页版的社区模块。**不做无头**：登录一次后
一直用同一个资料目录；登录态存本机数据目录 `xhs/edge-profile`，绝不上传。

## 她能做什么

- **刷**：逛推荐流、认真看笔记（标题/正文/赞藏评/热评）写进记忆；好玩的私聊分享给主人（v0.1 只发 QQ）。
- **点赞 / 收藏 / 评论**：评论是她用自己的人格现想的；每天各有上限，新号前几天上限减半，
  两次写操作之间强制间隔；遇到验证码当天自动停手并通知主人。
- **认链接**：别人发来 `xiaohongshu.com/explore/<id>`、`/discovery/item/<id>`、`xhslink.com` 短链
  或裸 24 位笔记 id，她都能点开看完再聊。
- **私信**：核对过主人的小红书号后，定时看主人的私信并回复；回复里写 `[去刷小红书]` 她就去刷一轮。
- **发帖（默认关）**：只能先存**草稿**，主人在面板（或主人私聊里用 `xhs_publish_confirm`）
  确认后才真的发——绝不闷头发。
- **视觉看图（默认关）**：逛到有配图的笔记，下载配图给模型看，画面描述写进她的观感
  （影响点什么赞、评论写什么）；整轮最多看 3 篇防慢。全局模型要支持图片才有效，
  面板「状态总览」里能看到她现在能不能看图。
- **截图库**：看过的图按概率（默认 30%）存下来，最多留 30 张（超了删最旧）；
  主人在聊天里说「发张截图 / 给我看看你刷到的」（`xhs_send_shot`）她就挑一张发过来，
  面板「截图库」卡可以浏览和删。验证码截图也会经图片通道直接发到主人 QQ。
- **关键词巡游**：设置里填关键词（每行一个），隔一轮搜一个（猫→狗→猫…交替），
  搜索轮的看/赞/评/分享与推荐轮走完全相同的安全闸（上限/间隔/试运行）。
- **真·@主人（默认关）**：评论里真的 @ 主人（主人会收到小红书通知）——只认「核对」写进来的
  主人号，面板改配置绕不过；每天上限默认 3 次；@ 候选里认不出主人就整条不发，绝不发假 @。
- **站内分享**：分享渠道可选 qq / dm（站内私信笔记卡片）/ both；站内那半是浏览器里的页面动作，
  失败自动回落 QQ；同一篇笔记绝不站内分享第二次。
- **回复评论（默认关）**：定时翻自己笔记下的新评论（第一次只记不回），挑该回的用她的人格回；
  每天上限默认 5 条，回复同样走间隔/试运行/验证码停手闸门；主人在聊天里说「回一下评论」
  （`xhs_reply_comments`）也能立刻回一轮。

## 面板

自定义面板 `panel.js`（index.mjs 里 `panel: 'panel.js'`），四张分区卡：

1. **总览**：标题行总开关 + 试运行（均即存）；仪表网格两行三列（登录 / 今日赞藏评回余量 /
   看图态 / 下一轮倒计时 / 截图库存 / 待确认草稿数）；暂停与跳过只在有值时出一条警示行；
   「去刷一轮 / 看私信 / 回新评论 / 刷新」四个等宽按钮；
2. **设置**：五组小节（巡游 / 互动能力 / @主人与回评 / 节奏与保护 / 视觉与截图）共用底部
   一个「保存设置」；滑块 label 左值右、固定宽；
3. **登录与身份**：扫码登录（二维码缩略 128px）/ 显示收起窗口 / 主人核对（已核对昵称 badge）
   三块并排，浏览器路径收成卡内最后一行小字输入框（即存）；
4. **产物**：Seg Tab 三视图——截图库（网格缩略+删除）/ 发帖草稿（Tab 标题带计数、红标
   「发布需主人确认」）/ 运行记录（最多 30 条单行列表）。

所有设置项未设置/为空时显示模块 defaults 兜底值（draft 模式：改动先存本地草稿、
点「保存设置」一次落盘，null = 不脏）；数值项用滑块 + 当前值显示。
即存项口径：总开关 / 试运行 / 浏览器路径 / 主人小红书号 四个，其余进草稿。

## 面板设置（无自定义面板的环境兜底）

总开关默认关。各能力独立开关（点赞/收藏/评论/分享/私信默认开，发帖默认关）；
每日上限：赞 20 / 藏 10 / 评 3 / 分享 5 / 发帖 1；每轮看 5 篇、停留 8~25 秒、
每天最多自动刷 4 轮、间隔 4 小时；试运行（dryRun）只记录不真动手。

## 权限档

工具受面板「权限」页 `profilePerms.xhs*` 管：`xhsBrowse` / `xhsLike`（含收藏）/
`xhsComment` / `xhsShareOwner`（含主人核对）/ `xhsDm` / `xhsPublish`。
没配过的档位默认**仅主人**；设成 `off` 整个关掉。

## 工具面

| 工具 | 用途 |
| --- | --- |
| `xhs_watch` | 打开一篇笔记看（链接/短链/id 都行） |
| `xhs_recent` | 查最近看过的笔记及真实链接 |
| `xhs_browse` | 现在去刷一轮推荐（主人开口要必分享） |
| `xhs_like` / `xhs_collect` | 点赞 / 收藏某篇笔记 |
| `xhs_comment` | 在某篇笔记下评论 |
| `xhs_send_dm` | 给指定用户发私信（target=主页链接或 userId） |
| `xhs_share_owner` | 主人点名时把某篇笔记分享到主人 QQ |
| `xhs_confirm_owner` | 主人核对TA的小红书号（input=主页链接或 userId） |
| `xhs_publish_draft` | 存发帖草稿（等主人确认） |
| `xhs_draft_list` | 查草稿清单 |
| `xhs_publish_confirm` | 主人确认 / 驳回草稿（仅主人私聊可见） |
| `xhs_send_shot` | 从截图库挑一张发当前聊天（主人说「发张截图」时用） |
| `xhs_shot_list` | 查截图库存（来自哪篇笔记、什么时候） |
| `xhs_reply_comments` | 现在去回一轮自己笔记下的新评论 |

新功能默认关的（视觉 / @主人 / 回评论）都要在面板手动打开；@主人 依赖「核对」过的主人号。

## 面板接口（模块相对，挂在 `/aurabot/api/ext/xhs/` 下）

`/state` `/account` `/login` `/login/status` `/window` `/run` `/share` `/dm` `/dms` `/confirm-owner`
`/drafts` `/draft/confirm` `/draft/reject` `/replies/run` `/shots` `/shot/delete` `/vision/state`
（`/draft/*` POST body 带 `id`；`/share` 带 `link`；`/dm` 带 `target`、`text`；`/shot/delete` 带 `file`）。

## 实现

- `lib/browser.mjs`：CDP 专用浏览器（改自抖音模块同款，MIT 同许可），新增 `setFiles`（发帖传图）、
  `cookies()`（读 HttpOnly cookie 判登录态）。
- `lib/site.mjs`：DOM 解析 + `waitResponse` 等接口回执；读数据不碰 `x-s/x-t` 签名，绝不自造签名。
- `lib/duty.mjs`：安全门（上限/间隔/新号减半/验证码停手/试运行）与草稿确认流。
- `lib/vision.mjs`：下载笔记配图（JPEG/PNG/WebP）交给视觉模型；`canSeeImages` 不支持就安静跳过。
- `lib/shots.mjs`：截图库（md5 去重、maxKeep 裁剪）。
- 测试：`test/xhs.test.mjs`，假浏览器 + 假 site 注入，不打真网络。

## 真机实测（v0.2.0，2026-11-06，主人真实登录态）

用真实小红书账号逐项验过，13 项通过 / 0 失败 / 2 项跳过（需主人号或该笔记无配图）：

| 项 | 结果 |
| --- | --- |
| 登录态识别（CDP 读 `web_session`） | ✅ userId 正确 |
| 刷推荐流 / 关键词搜索 | ✅ 各 20 条，全带 `xsec_token` |
| 打开并读笔记 | ✅ 标题/作者/赞藏评/热评/配图 |
| 点赞 / 收藏 / 发表评论 / 回复评论 | ✅ 均有接口回执确认 |
| 读评论区（含序号，供回评定位） | ✅ |
| 笔记截图 / 截图库存取 | ✅ |
| 链接识别与摘要（explore / 短链 / 裸 id） | ✅ |

跳过：**主人私信**（需先核对主人小红书号）、**该轮无配图笔记的视觉描述**（配图下载与 WebP 识别已单独验过）。

真机踩到并已修掉的关键坑（都写进了代码注释，防再犯）：

1. **窗口必须在屏幕内** —— 放到 `-2400,-2400` 时 Edge 会清布局，卡片 `getBoundingClientRect()`
   全变 0×0，真鼠标点不到、笔记一律 404。改为起始位置 `80,60`。
2. **卡片里有多个 `a`**，第一个常是 `display:none` 的空链接且不带 token；取错就丢 `xsec_token` → 404。
   必须优先取带 `xsec_token` 的那个。
3. **打开笔记必须带 `xsec_token`**（`?xsec_token=…&xsec_source=pc_feed`），裸链接必 404。
4. **登录态只能靠 HttpOnly cookie `web_session`** —— 页面里 `document.cookie` 读不到它，
   `/api/sns/web/v2/user/me` 裸调 500，`__INITIAL_STATE__` 是加载时的静态快照（扫码后不变）。
5. **DOM 选择器全部按真机校正**：互动按钮是 `.like-wrapper` / `.collect-wrapper` / `.chat-wrapper`
   （**没有** `.interact-container` 那层）、激活态是 `like-active` 不是 `active`、
   评论输入框是 `#content-textarea`（`p.content-input`）、发送按钮是 `button.btn.submit`。
6. **评论发送必须用 DOM `click()`** —— 评论栏在页面里被模糊遮挡，真鼠标坐标点不到，
   点了既没反应也拿不到回执。
7. **配图是 WebP** —— 只认 JPEG/PNG 魔数会导致所有图下载失败；已补 WebP 识别与 `mediaTypeOf`。
