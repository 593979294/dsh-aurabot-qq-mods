# 小票打印

把模板和提示词变成一张热敏小票。给模板写好提示词，接上打印机，就能手动触发或按时间自动生成并打印；她发空间说说时也会自动排版打印，配图按纸宽缩放，打完自动切纸。

## 它做什么

- **模板 + 提示词**：每个模板一条提示词，支持 `{date}` `{weekday}` `{time}` `{datetime}` `{width}` `{paper}` `{effective}` `{columns}` `{name}` 占位符。
- **生成方式**：`单问模型`（`api.ask`，快、不带人格）或 `让她想`（`api.think`，带人格和记忆，慢）。
- **定时或手动**：模板可设 `HH:MM` 和星期，同一天同一模板只触发一次；也可以随时发命令或点面板按钮。
- **纸宽自适应**：按毫米设置纸宽和有效打印宽度，自动换算每行列数，中文折行不会溢出。
- **一键自检**：面板按钮、`/自检` 或 `/打印机 自检`；默认发内置 ESC/POS 自检页，可替换成自己的十六进制指令。
- **排版**：页眉、分隔线、页脚、二维码、走纸、半切/全切。
- **打印通道**：Windows 打印队列（USB）、网口 9100、macOS/Linux CUPS；没有打印机时用「只预览」。
- **单台打印机**：面板里填一台机器的名字、通道和纸宽，所有模板共用。
- **说说自动打印**：监听内置 `diary` 模块，她每次发空间说说后自动排版打印；配图按有效纸宽缩放成黑白位图，打完自动切纸。

## 安装

模块市场安装，或把 `modules/receipt-print/` 整个放进：

```text
<数据目录>/modules/receipt-print/
```

数据目录默认是 `~/.dsh/plugins-data/aurabot/`。模块数据、模板和打印记录在 `modules-data/receipt-print/`。

## 打印机怎么接

### Windows + USB（最常见）

1. 装打印机原厂驱动，在「设置 → 蓝牙和其他设备 → 打印机和扫描仪」里确认能打印测试页。
2. 记下打印机的**队列名**（就是列表里显示的名字，例如 `POS-58`、`XP-58`）。
3. 面板 →「打印机」→ 传输方式选 `Windows 打印队列（USB）`，目标填队列名。

模块通过 PowerShell 调 `winspool.drv` 的 `WritePrinter`，把 ESC/POS 原始字节直接写进队列，不经过驱动的文字渲染。要求驱动接受 RAW 数据（多数热敏机原厂驱动可以）。

### 网口 / WiFi

打印机设置里打开 RAW 打印或 9100 端口，面板里传输方式选 `网口 / WiFi（9100）`，目标填 `192.168.x.x`（端口默认 9100，也可以写 `IP:端口`）。

### macOS / Linux

先在 CUPS 里建好队列，传输方式选 `macOS / Linux CUPS`，目标填队列名。模块执行 `lp -d <队列> -o raw -`。

### 没有打印机

把面板里的传输方式设为 `只预览`，或干脆不配置。生成结果会作为文字回到聊天/面板。

## 设置

| 设置 | 说明 |
|---|---|
| 启用 | 关掉后定时不触发，命令会提示已关闭 |
| 纸宽（mm） | 常见 58 / 80，也可以填 40、110 等；默认 58 |
| 有效打印宽度（mm） | 纸的可用宽度，`0` = 自动（58→48mm，80→72mm）；每行字符数由它换算 |
| 自检指令 | 十六进制，留空走内置 ESC/POS 自检页；填了就原样发送，不再发内置页 |
| 中文编码 | `GBK`（多数国产机）或 `UTF-8` |
| 切纸 | 半切 / 全切 / 不切 |
| 正文最大字数 | 模型输出超长会截断 |
| 打印页眉 | 模板名、日期时间、分隔线 |
| 全局页脚 | 所有模板默认页脚，模板可覆盖；支持占位符 |
| 二维码内容 | 留空不打印；支持占位符 |
| 打印超时 | 默认 8 秒，连不上就报错，不阻塞聊天 |
| 说说自动打印 | 她发空间说说后自动排版打印，默认开 |
| 连仅自己可见的也说打印 | 默认关；`diary` 里 `visibility: self` 的条目不打 |
| 打印说说配图 | 默认开；配图按有效纸宽缩放 |
| 每条说说最多打印几张图 | 默认 3；`0` = 只打文字 |
| 图片最大高度（mm） | 默认 100；超高的图会整体缩小，避免一张图打太久 |
| 图片抖动 | 默认开，照片层次更自然；关掉是纯黑白阈值，适合文字截图 |
| 自动调色（色阶） | 默认开，自动拉开明暗，避免整张灰蒙蒙或糊成黑块 |
| 图片亮度 / 对比度 | 默认 0；热敏纸偏黑可调低亮度、调高对比度 |
| 图片伽马 | 默认 1.3，大于 1 提亮暗部（墨点会胀，稍提亮更耐看） |
| 图片锐化 | 默认开，文字截图和小图边缘更清楚 |

### 纸宽怎么换算

203dpi 热敏机是 8 dots/mm，Font A 一个半角字符 12 dots 宽：

```text
每行列数 = floor(有效宽度mm × 8 ÷ 12)
58mm 纸 → 48mm 有效 → 32 列（中文 16 字）
80mm 纸 → 72mm 有效 → 48 列（中文 24 字）
40mm 纸 → 30mm 有效 → 20 列（中文 10 字）
```

如果打出来右边留白太多或文字被切，就把「有效打印宽度」调大/调小，不用改代码。

### 一键自检

面板「打印机」里有「保存并自检」；命令是 `/自检` 或 `/打印机 自检`。

默认自检页由模块用 ESC/POS 生成，包含：打印机和通道信息、纸宽/有效宽度/列数、编码、中文与 ASCII 样例、一行铺满宽度的数字刻度尺、二维码、走纸和切纸。刻度尺正好到纸边，就说明有效宽度设置对了。

要发厂商自己的自检或特殊指令，在「设置 → 自检指令（十六进制）」里填，例如：

```text
1B 40 1B 61 01 48 65 6C 6C 6F 0A 1B 64 03 1D 56 42 00
```

支持 `1B 40`、`0x1B,0x40`、`1B401B61` 三种写法。填了之后自检会原样发送这段字节（不再追加模块生成的内容），所以切纸、走纸也要自己写进去。

### 说说自动打印

模块每 30 秒读一次内置 `diary` 模块的 `history()`：

1. 只处理比上次水位更新的说说；第一次启动只记下当前位置，不会把历史说说全打一遍。
2. 默认跳过 `visibility: self`（仅自己可见）的条目；打开「连仅自己可见的也说打印」才打。
3. 正文按小票纸宽折行，页眉显示「说说」和发布时间，页脚、二维码跟全局设置走。
4. 配图从 `images` / `pics` / `photos` / `media` 字段，或正文里的 Markdown 图片、图片直链里取；单张最大 8MB，只支持 JPEG / PNG。
5. 图片铺满有效纸宽（58mm 纸 = 384 dots），太高会等比缩到「图片最大高度」；缩完先自动色阶，再按设置做亮度/对比度/伽马和锐化，最后抖动或阈值成 ESC/POS `GS v 0` 光栅位图。热敏纸只有黑点，调色比单纯缩放更影响可读性。
6. 一张小票的正文和图片都发完，统一走纸并按「切纸」设置半切/全切。

如果宿主版本的 `diary` 没有暴露 `history()`，或者历史里不带图片字段，模块会静默跳过/只打文字，不会影响其他功能。

## 命令（仅主人）

| 命令 | 作用 |
|---|---|
| `/小票` | 看模板列表 |
| `/小票 名称` | 生成并打印该模板 |
| `/小票 预览 名称` | 只生成版面，不发打印机 |
| `/小票 加 名称 \| 提示词` | 快速新建模板 |
| `/小票 删 名称` | 删除模板 |
| `/小票 自检` | 打自检页 |
| `/打印 内容` | 直接打印一段文字 |
| `/打印机` | 看打印机、纸宽和列数 |
| `/打印机 自检` | 打自检页 |
| `/自检` | 一键自检 |

命令只认主人，群成员发这些命令不会触发打印。

## 模板字段

面板里编辑：

- **名称**：也是 `/小票 名称` 的引用名。
- **提示词**：发给模型的正文，支持占位符。
- **系统提示词**：可空，默认要求纯文本、不要 Markdown。
- **生成方式**：`单问模型` 或 `让她想`。
- **定时**：开关、时间、星期（不选=每天）。
- **纸张**：跟随打印机，或强制 58 / 80mm。
- **页脚 / 二维码**：可空，支持占位符。

定时判定是「当前分钟等于设定时间」，所以机器人需要在那个时间点运行。补跑不会自动发生，避免重复出纸。

## 数据与隐私

- 模板、打印记录、`lastRun` 都存在 `modules-data/receipt-print/state.json`。
- 打印记录只存模板名、打印机、成功/失败、字数，不存生成正文。
- 生成走 `api.ask` / `api.think`，和插件其他模型调用一样。

## 已知限制

- Windows USB 通道依赖 `winspool.drv` 和原厂驱动，代码在 Linux 上只做了命令构造测试，**没有在真机 Windows 上验证**；第一次用请先打自检页。
- 自检的列数按 203dpi / 12 dots 字符宽计算；如果你的机器是 300dpi 或换过字体，用「有效打印宽度」微调即可。
- 图片只支持 JPEG / PNG，不处理 EXIF 方向；手机竖拍照片如果打出来是横的，先转正再发。
- 打印机离线时会在超时后报错，不会自动重试排队。
- 需要 Node 22+。

## 开发

```sh
cd modules/receipt-print
npm ci
npm test          # 布局、字节、模板、传输、存储、图片、说说
npm run build     # 产出 .build/
```

测试不依赖真打印机：网口用本地假 TCP 服务器，Windows/CUPS 用注入的 spawn 断言命令参数。
