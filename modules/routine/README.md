# 作息 · routine

她一天里的骨架：上班/上学、通勤、在家休息、请假调休，由这张作息表判定。**只有「在家休息」的时段才让过日子（livin）醒来**——上班时间她不会自己找乐子，到家了才过自己的日子。

## 它管什么

- **状态机**：`睡觉 / 通勤 / 上班中 / 在家`，每 5 分钟对一次表，状态切换沿才动作
- **三层日程**（上层覆盖下层）：
  1. `overrides`：请假日（压力攒满自动挂，或面板手动加）
  2. `disturb`：每周日自动生成的下周扰动——临时加班（休息日变上班）、调休（上班日变休息），一周最多两条
  3. `self`：她自己用 `life_schedule` 工具记的日程（「周三要值班」「明天下午开会」）
  4. 底座：每周固定班表（面板里编辑，默认周一到五 9:00–18:00）
- **压力值**：工作日 +10、休息日 -15、请假 -25（可调），攒到阈值第二天自动请假，并顺手给心情记一笔（`nudge`，原因不含聊天内容）
- **注入【此刻·作息】**：≤100 字，只描述处境不下指令（「现在是上班时间…只能偶尔偷偷看下手机」），末尾固定带画图免责——别把「上班」画进画里
- **控制 livin**：只在状态沿拨 `ext.livin.enabled`，深合并只改这一个键；同一个状态内你在 livin 面板手动开关不会被抢回，到下一个状态沿才纠正

## 存储

- `modules-data/routine/schedule.json`：每周班表
- `modules-data/routine/routine.json`：压力值 + 自记日程 + 扰动 + 判定历史（7 天）

## 面板

「已安装 → 作息」：托管开关、当前处境、压力条、接下来的安排（可取消）、每周班表编辑、判定痕迹（每次翻日结账、状态切换、开关拨动都留痕）。

## 测试

`.workbuddy/tests/routine.test.mjs`（node:test）：状态机各分支、三层覆盖优先级、注入文本长度与免责、压力翻日结账与请假触发、扰动生成上限、存盘原子化。
